# Silueta Demo

An interactive papercraft storytelling game built with Unity (URP). Players manipulate translucent layers, color filters, and dynamic cutout mechanics to reveal hidden silhouettes and narratives.

## Architecture & Tech Stack
- **Engine:** Unity (2D Universal Render Pipeline)
- **Core Mechanics:** Runtime texture manipulation (RenderTexture), 2D raycasting, and depth-based masking.
- **Design Pattern:** Object-Oriented modular structure.

- [x] Phase 1: Engine Setup & 2D URP Environment
